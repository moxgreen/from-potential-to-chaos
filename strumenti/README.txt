Laboratorio del potenziale elettrostatico

Come aprire i file:
  1. Estrai lo zip in una cartella.
  2. Fai doppio clic su un file .html: si apre nel browser (Chrome, Firefox, Safari, Edge).
     Non servono installazioni, server né connessione a Internet.

Contenuto:
  potenziale-cariche.html               il simulatore
  lezione-dal-potenziale-al-caos.html   la lezione (canovaccio, note per il relatore, testo per lo studente)
